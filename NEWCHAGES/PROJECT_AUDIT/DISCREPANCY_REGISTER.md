# NovaNest — Master Discrepancy Register & Resolution Playbook

## 1. Comprehensive Discrepancy Tracking
Every identified architectural, data, formula, and model discrepancy is documented and prioritized below:

| ID | Domain | Discrepancy Description | Root Cause | Impact | Resolution / Current Status | Priority |
|---|---|---|---|---|---|---|
| **DISC-01** | Architecture | Dual-root directory structure (`NovaNest-main` vs `Capstone/NovaNest/NovaNest`) | Historical branching during Capstone delivery | Risk of fragmented development | Unified audit reconciling both roots. Source of truth established. | High |
| **DISC-02** | Machine Learning | Customer Churn model reports 1.0000 ROC-AUC & 0.995 accuracy | Feature leakage: `Recency` directly correlates with synthetic churn label rule | Model lacks real-world generalization | Documented in audit. Remediation: Retrain with temporal cutoff window. | High |
| **DISC-03** | Machine Learning | Delivery ETA model reports $R^2 = 0.38$ (earlier reports claimed 0.9946) | Synthetic distance/prep formula shortcut vs realistic traffic noise | Unrealistic documentation claim | Corrected in audit. Documented that traffic telemetry is required for $R^2 > 0.80$. | Medium |
| **DISC-04** | Analytics / KPI | AOV reported as ₹967.33 (Net) vs ₹970.75 (GMV) | Inconsistent numerator (Net Revenue vs Total GMV) across completed orders | Confusion between gross vs net spend | Formally resolved in Phase 4. Both metrics defined and tested in `kpi_engine.py`. | High |
| **DISC-05** | Analytics / KPI | Contribution Margin reported as 23.60% vs 24.54% | Historical calculation excluded payment gateway fees and misallocated rider costs | Underestimated true platform profitability | Mathematically reconciled to 24.54% (Profit ₹11,393,907.16 / Net Rev ₹46,425,992). | High |
| **DISC-06** | Database / SQL | Archive `08_phase3_intelligence.sql` has raw queries instead of permanent views | Rapid prototyping script without DDL encapsulation | Requires manual execution for analytics | Resolved in workspace by deploying `08_phase3_analytical_views.sql` with 6 DDL views. | Medium |
| **DISC-07** | Frontend / UI | Redundant dual frontend implementations (Streamlit vs React 18) | Parallel prototyping during Capstone evaluation | Maintenance overhead for UI features | Roadmap clarified: React 18 is production client; Streamlit is DS sandbox. | Medium |
| **DISC-08** | Artificial Intel | Universal AI claims 100% LLM uptime without internet/API key | Unclear documentation regarding `MockProvider` fallback mechanism | User expectation mismatch | Documented: `MockProvider` delivers deterministic heuristic fallback when offline. | Low |
| **DISC-09** | Data Pipeline | Duplicate engineered datasets (`orders_engineered.csv` vs `orders_geo_temporal_enriched.csv`) | Historical naming transition across phases | Redundant disk storage (~7 MB) | Verified bit-for-bit identical. Preserved for backward compatibility. | Low |
