# PHASE 06 — ARCHITECTURE & DELIVERY RISK REGISTER

- **Status**: `PROPOSED`

| Risk ID | Risk Description | Category | Severity | Likelihood | Concrete Mitigation Strategy |
|---|---|---|---|---|---|
| **R-06-01** | **Unreliable Phase 05 ML Over-Trust**: Users or LLMs treat Churn (`ROC-AUC 0.5161`), ETA (`R2 -0.0002`), Demand (`city R2 < 0`), or Leakage (`4,669` IQR flags) as high-confidence facts. | Business / ML Accuracy | **Critical** | High | Enforce structured `ml_confidence_warnings` + `confidence_pct = None` across all agents; render explicit amber caveats in React/Streamlit; block *"Confirmed Loss"* phrasing in `OutputVerifier`. |
| **R-06-02** | **Residual Hardcoding Propagation**: Legacy hardcoded numbers (`32.4m`, `412`, `East Hub`, `₹12.50L`) leak through fallbacks in `root_cause.py` or `data_grounding.py`. | Grounding Integrity | **High** | High | Execute **Phase 06.0** stabilization first; delete static fallback prose entirely, replacing missing columns with explicit `"Unavailable — column missing"` markers + automated anti-hardcoding regression tests. |
| **R-06-03** | **LLM Arithmetic Hallucination / Contradiction**: External Gemini model invents figures or mixes `GMV (₹4.66 Cr)` with `Net Revenue (₹4.64 Cr)`. | AI Reliability | **High** | Medium | Restrict Gemini strictly to post-computation narration over `<verified_context>`; run deterministic `OutputVerifier` numeric check failing closed to template prose on mismatch. |
| **R-06-04** | **Prompt Injection & Cross-Tenant Memory Leak**: Attacker injects instruction override via chat/review text, or two users sharing `"session_id": "default"` read each other's business context. | Security | **Critical** | Medium | Implement `InputShield`, XML data fencing, per-agent table ACLs, and HMAC principal-scoped `ScopedSessionKey` isolation with `30m` TTL + `RLock`. |
| **R-06-05** | **Multi-Agent Latency Spike**: Sequential domain agents + heavy DataFrame recomputation causes `/api/ai/ask` to exceed UX SLA (`> 3s`). | Performance | **Medium** | Medium | Run Wave 1 domain agents concurrently via `ThreadPoolExecutor(max_workers=4)` with `3.0s` per-agent deadline; pre-compute/cache lightweight KPI & readiness snapshots keyed by CSV `mtime_ns`. |
| **R-06-06** | **Live MySQL Unavailability (`BLOCKED` `1045`)**: Live MySQL fails authentication during Phase 06 development/testing. | Infrastructure | **Medium** | High | Build Tier-1 `CSV File Store + 9-table RO SQLite` as self-contained primary execution backend (`Parity 100%`), keeping `execute_query` MySQL path cleanly modular for instant cutover once host `.env` credentials are configured. |
| **R-06-07** | **Operator `HTTP 403` on Session Reset**: Currently `/api/ai/reset` requires `admin` while `/api/ai/ask` only requires `operator`, breaking UI "New Chat". | Auth / UX | **Medium** | High | Remediate `/api/ai/reset` in Phase 06.5 to accept `operator` scoped strictly to their own `ScopedSessionKey`. |
| **R-06-08** | **Streamlit Page 07 Drift**: `07_Ask_NovaNest.py` continues diverging via deprecated `python/ai/conversational/*` without SQLite read-only lock or `commissioned` scenario keys. | UI Consistency | **High** | High | Deprecate legacy direct pipeline on Page 07 in Phase 06.6, delegating cleanly to unified `MasterOrchestrator` + `9`-table `configure_readonly_sqlite` sandbox. |
